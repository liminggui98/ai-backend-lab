## 职位描述

### 团队介绍

字节跳动开发者服务团队负责公司研发工具与基础设施体系建设，为内部开发者提供覆盖全技术栈的框架、工具和研发体系能力，支撑业务高效稳定迭代。在此基础上，团队正打造面向全场景的 AI Agent 平台，将大模型与公司内部工程知识深度结合，覆盖需求分析、编码开发、测试发布、运维治理等软件全生命周期，帮助 ByteDancer 显著提升生产力，重塑开发者服务的形态与体验。期待对研发工具体系、AI 工程生产力有热情、希望在大规模真实场景中打磨技术的同学加入，与我们一起建设新一代开发者基础设施，共同成长！

### 岗位职责

1. 参与字节跳动公司级研发提效 AI Agent 和相关产品开发；
2. 借助数据分析、用户调研、业界分析，主动挖掘相关场景，推进功能建设；
3. 借助评测，Prompt 优化，知识优化等能力，优化相关场景的效果和体验；
4. 通过成品和工程建设，优化相关场景用户体验。

### 职位要求

1. 2027 届获得本科及以上学历，计算机、通信和电子信息科学等相关专业优先；
2. 至少熟练掌握一门编程语言（C/C++/Golang/Java/Python/PHP 等）；
3. 有优秀的逻辑分析能力，能够对业务逻辑进行合理的抽象和拆分；
4. 有强烈的求知欲，优秀的学习和沟通能力。

## 关键词提炼

- 团队定位：开发者服务 / 研发基础设施，做面向全场景的 AI Agent 平台
- 业务链条：需求分析 → 编码开发 → 测试发布 → 运维治理（覆盖软件全生命周期）
- Agent 工作内容：研发提效 Agent 产品开发、场景挖掘、效果评测、Prompt 优化、知识优化
- 画像要求：2027 届校招，编程语言一门即可，重逻辑抽象与学习能力（**不要求工作经验**）
- 技术栈标签：Golang / Java / C++ / Python / PHP、infra、MySQL、系统架构设计经验
- 关键差异：这是本库中唯一面向**在校/应届**的 Agent 岗位，其余均为社招
