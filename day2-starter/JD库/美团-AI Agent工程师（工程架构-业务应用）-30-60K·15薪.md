## 职位描述

### 岗位职责

1. 负责面向商家的 B 端 AI Agent 应用建设，围绕商家经营、商品管理、订单履约、客服售后、营销运营、数据分析等场景，提升商家工作效率和经营效果。
2. 参与 AI Agent 基础框架能力建设，包括 Agent 编排、工具调用、任务规划、上下文管理、记忆机制、权限控制、工作流、人机协同、异常兜底等核心模块。
3. 将商家高频业务流程抽象为可复用的 Agent 能力和业务组件，如经营助手、商品助手、客服助手、营销助手、数据分析助手等。
4. 负责 Agent 与内部业务系统、数据平台、知识库、运营工具、CRM / 工单 / 商家后台等系统的集成。
5. 建设 Agent 应用的工程化能力，包括 Prompt 管理、工具注册、链路追踪、效果评估、灰度发布、成本控制和稳定性治理。
6. 与产品、算法、业务运营、商家服务团队协作，完成从业务场景识别、方案设计、原型验证到上线迭代的闭环。

### 岗位要求

1. 本科及以上学历，计算机、软件工程、人工智能等相关专业优先。
2. 熟悉 Java / Go / Python / TypeScript 中至少一种语言，具备扎实的后端或全栈开发能力。
3. 有 B 端产品、商家后台、SaaS、CRM、客服系统、运营平台、工作流系统等业务系统建设经验。
4. 理解 LLM 应用开发范式，熟悉 Prompt Engineering、RAG、Function Calling、Agent Workflow、工具调用等能力。
5. 具备良好的平台化和抽象能力，能够从具体商家场景中沉淀通用 Agent 框架、组件和方法论。
6. 对业务有敏感度，能够理解商家经营链路，并将复杂业务流程拆解为可自动化、可评估、可迭代的 Agent 任务。

### 岗位亮点

1. 直接参与商家 B 端 AI 应用从 0 到 1 建设，覆盖商家经营、营销、客服、商品、订单、数据分析等核心场景。
2. 同时负责业务 Agent 应用落地和 Agent 基础框架建设，既能做业务闭环，也能沉淀平台能力。
3. 场景真实、高频、复杂，适合将 LLM / Agent 技术落到可衡量的业务效率和经营结果中。
4. 有机会建设通用 Agent Framework，包括工具调用、任务编排、记忆机制、权限体系、评测体系、可观测性等核心能力。
5. 与产品、算法、业务运营、商家服务团队深度协作，能完整参与从需求识别、方案设计、工程实现到效果验证的全过程。
6. 方向处于 AI 应用落地早期阶段，技术空间和业务空间都足够大，适合希望做 AI Native B 端产品和平台能力的人。

### 具备以下优先（本版本独有）

1. 有商家经营、广告营销、电商、零售、本地生活、供应链、客服售后等 B 端业务经验。
2. 有 AI Agent 平台、智能客服、商家助手、运营助手、数据分析助手等项目经验。
3. 熟悉 LangChain / LangGraph / LlamaIndex / Dify / Coze / AutoGen / CrewAI / MCP 等框架或协议。
4. 有权限体系、插件系统、工作流引擎、企业知识库、可观测性平台建设经验。
5. 有从 0 到 1 搭建 Agent 基础框架，或推动 AI 应用在业务团队规模化落地的经验。

## 关键词提炼

- 岗位定位：B 端商家 Agent（工程架构 + 业务应用），与 40-70K 版本同源

- 工程化：Prompt 管理、工具注册、链路追踪、效果评估、灰度发布、成本控制、稳定性治理
- 生态框架（优先项）：LangChain、LangGraph、LlamaIndex、Dify、Coze、AutoGen、CrewAI、MCP
- 业务经验（优先项）：商家经营、广告营销、电商、零售、本地生活、供应链、客服售后
- 平台能力（优先项）：权限体系、插件系统、工作流引擎、企业知识库、可观测性平台
