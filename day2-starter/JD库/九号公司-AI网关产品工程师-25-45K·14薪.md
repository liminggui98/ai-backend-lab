## 职位描述

### 岗位职责

1. 负责公司统一 AI 网关的产品规划设计与持续运营，作为全公司大模型调用的统一入口与治理中枢。
2. 对接外部第三方 Provider 商务和技术对接管理，如华为云、阿里云、百度智能云、DeepSeek 等主流 MaaS 厂商 API，建立统一模型接入层与路由层等。
3. 设计并实现智能路由策略，基于成本、延迟、质量、合规要求进行模型动态路由与流量调度。
4. 建立 Token 成本治理体系，包括预算管理、限流控制、成本分摊、多维度（部门/项目/用户）报表与分析。
5. 负责 AI Gateway 的模型可观测，安全护栏等基线能力等规划落地。
6. 负责 AI 网关高可用性落地，包含网关自己身高可用，以及多 Provider 容灾切换、降级策略与全链路 SLA 监控告警。
7. 为内部业务团队提供统一 SDK、API 文档与技术支持，推动 AI 能力在业务侧高效落地。

### 任职要求

1. 本科及以上学历，计算机、软件工程等相关专业，5 年以上相关工作经验。
2. 熟悉主流 MaaS 厂商 API（阿里云、Azure OpenAI 等），了解大模型调用机制与 Token 计费逻辑。
3. 熟悉各类 Request message 协议，熟悉 MCP，SkillHub 等场景 AI 相关服务。
4. 熟悉 API 网关技术（如 Kong、APISIX 等），有高并发、低延迟系统设计与调优经验。
5. 熟练掌握至少一门主流编程语言（Go/Java/Python），有良好的编码习惯与工程素养。

### 加分项

- 有大模型应用开发或 LangChain/LlamaIndex 等框架使用经验。
- 有后端开发或 API 网关相关经验，有 AI 网关/LLM API 网关项目经验者优先。

## 关键词提炼

- 产品定位：公司级统一 AI 网关，大模型调用的统一入口与治理中枢（偏产品 + 工程复合岗）
- 生态对接：华为云、阿里云、百度智能云、DeepSeek 等 MaaS 厂商；统一接入层、路由层
- 路由调度：按成本 / 延迟 / 质量 / 合规做动态路由与流量调度
- 成本治理：Token 预算管理、限流、成本分摊、多维度报表（部门/项目/用户）
- 平台能力：模型可观测、安全护栏、统一 SDK、API 文档
- 高可用：多 Provider 容灾切换、降级策略、全链路 SLA 监控告警
- 技术栈：Kong / APISIX、MCP、SkillHub、LangChain / LlamaIndex、Go / Java / Python
