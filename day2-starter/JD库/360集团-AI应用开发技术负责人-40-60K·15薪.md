## 职位描述

### 岗位职责

1. 负责 AI Agent 应用研发团队的整体技术管理，对产品交付质量、工程效率、系统稳定性和团队能力建设结果负责。
2. 制定并落地 Agent 产品技术架构与演进路线，覆盖 Agent Runtime、模型/工具网关、多端交互、本地运行环境、任务编排、可观测与评测体系，保障端到端链路可扩展、可治理、可迭代。
3. 建立 AI First 工作模式，将个人提效升级为团队工作方式，持续提升交付效率和质量。
4. 建设组织与人才机制，带出能独立扛模块、能跨方向协同的 AI Native 研发团队。

### 任职要求

1. 本科及以上学历，计算机、软件工程、人工智能相关专业；具备 8 年及以上软件研发经验，其中至少 5 年技术管理或 Tech Lead 经验，带过跨端/跨方向团队优先。
2. 有完整 AI 应用落地经验，理解从模型调用、工具执行、任务编排到多端交互与本地运行环境的端到端链路，能对非确定性系统做工程化治理。
3. 技术栈需具备足够深度与广度：至少精通服务端（Go/Python）、前端（React/TypeScript）、Agent 引擎、桌面端（Electron 等）中的两个以上方向，并能对另外方向做有效技术判断与决策。
4. 具备复杂系统设计与架构治理能力，熟悉分布式系统、实时通信（SSE/WebSocket）、任务调度、状态一致性、可观测性及发布稳定性治理。
5. 熟悉 Agent 核心机制与工程实践，包括 Agent Loop、Function Calling、MCP/Tool/Skills、RAG、Context/Memory、评测体系、Prompt/Skill 资产化及多 Agent 协作。
6. 具备扎实的工程管理能力：能制定技术规划与里程碑，建立交付节奏、质量门禁、复盘机制和考核抓手。
7. 具备优秀的组织协同与管理判断力，能处理跨方向依赖、优先级冲突和关键人风险，擅长用清晰原则推动共识，对人、事、结果同时负责。

## 关键词提炼

- 角色定位：技术负责人 / Tech Lead，带 8 人以上团队，对交付质量、工程效率、稳定性、人才梯队负责
- 架构范围：Agent Runtime、模型/工具网关、多端交互、本地运行环境、任务编排、可观测与评测
- Agent 机制：Agent Loop、Function Calling、MCP/Tool/Skills、RAG、Context/Memory、Prompt/Skill 资产化、多 Agent 协作
- 技术栈：Go / Python、React / TypeScript、Electron、SSE / WebSocket、分布式系统、任务调度
- 工程治理：非确定性系统工程化、状态一致性、发布稳定性、质量门禁、里程碑与复盘
- 组织能力：AI First 工作模式、跨端/跨方向协同、优先级冲突处理
