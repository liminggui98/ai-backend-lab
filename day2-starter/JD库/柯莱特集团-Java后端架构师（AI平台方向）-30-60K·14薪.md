## 职位描述

### AI 中台方向

#### 岗位职责

1. 主导 AI 中台建设（含数据预处理、标注、训练、推理、模型中心），制定技术规划；
2. 负责系统设计、核心代码编写与 Code Review，确保高可用、可扩展；
3. 持续优化重构现有平台，提升性能与稳定性；
4. 攻克技术难点，引入并落地 AI 新技术，提升团队技术影响力。

#### 岗位要求

1. 本科及以上，5 年以上研发经验，具备 AI 工程系统落地经验；
2. 精通 Java，熟悉内存模型、多线程、并行计算、网络 IO、异构计算；
3. 精通分布式中间件（微服务、NoSQL、消息队列、ZK、ElasticSearch 等）；
4. 有 CV/NLP/推荐/搜索/知识图谱等项目经验者优先；
5. 具备技术架构力与团队领导力，能带领团队解决复杂问题。

## 关键词提炼

- 角色定位：后端架构师（AI 平台方向），兼顾架构设计与核心编码、Code Review、带团队
- AI 中台：数据预处理、标注、训练、推理、模型中心、技术规划
- Java 深度：内存模型、多线程、并行计算、网络 IO、异构计算
- 分布式：微服务、NoSQL、消息队列、ZK、ElasticSearch、高可用、可扩展
- 算法场景：CV、NLP、推荐、搜索、知识图谱（加分）
- 平台治理：优化重构、性能与稳定性、新技术落地
