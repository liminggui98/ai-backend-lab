## 职位描述

### 岗位职责

1. 负责智能设备自动化平台后端全流程研发，覆盖需求设计、编码、联调、上线与运维，搭建设备管理、任务调度、数据集、实时链路、网关、飞书协同、模型接入、AI Agent 等能力；
2. 搭建平台基础服务模块，针对高并发分布式场景做架构迭代与性能优化，保障系统可扩展、高稳定；
3. 负责接口、数据模型、缓存、消息、实时通信等方案设计落地，落地限流、熔断、幂等、重试等高可用机制；
4. 设计开发多 Agent 协同框架，实现 Agent 调度编排、消息通信、工具调用、多智能体协作、记忆管理等能力；
5. 跟进大模型、AI Agent 前沿技术，结合业务完成技术调研与落地；定位线上故障并闭环优化，完善监控治理体系。

### 任职要求

1. 本科及以上学历，计算机、人工智能、软件工程等相关专业；
2. 扎实 Java 基础，熟悉多线程、JVM、IO/NIO；熟练 Java17、Spring 全家桶、MyBatis-Plus、Maven 多模块开发；
3. 精通 MySQL、Redis、Kafka、ES 等中间件，掌握 SQL 优化、缓存、消息队列使用；熟悉 gRPC/Thrift、HTTP、WebSocket 多协议开发；
4. 具备分布式高并发项目经验，熟练接口治理、限流熔断、幂等重试、分布式调度等稳定性方案；
5. 了解 AI Agent、大模型工程化，懂调度编排、工具调用、上下文管理；有 LangChain、多 Agent 工作流、模型路由、Token 优化实践，或云原生 K8s、设备自动化平台相关经验优先；
6. 擅长业务抽象建模，可独立输出技术方案、排查线上问题；具备良好编码规范与团队协作能力。

## 关键词提炼

- 岗位定位：大模型应用后端（Java 方向），既做平台基础服务，也做多 Agent 协同框架
- 业务载体：智能设备自动化平台（设备管理、任务调度、数据集、实时链路、网关、飞书协同）
- Agent 能力：多 Agent 协同框架、调度编排、消息通信、工具调用、记忆管理、模型接入
- Java 深度：Java 17、多线程、JVM、IO/NIO、Spring 全家桶、MyBatis-Plus、Maven 多模块
- 中间件与协议：MySQL、Redis、Kafka、ES、gRPC/Thrift、HTTP、WebSocket
- 稳定性：限流、熔断、幂等、重试、分布式调度、监控治理
- 加分项：LangChain、多 Agent 工作流、模型路由、Token 优化、云原生 K8s、设备自动化平台
