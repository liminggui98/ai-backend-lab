## 职位描述

### 岗位职责

1. 参与云端 AI 服务的研发工作，包括需求沟通、功能设计与开发等；
2. 负责相关业务服务器相关的并发架构设计开发、线上维护等；
3. 和产品/测试/运营进行密切沟通，能够根据需求提出合理技术方案；
4. 跟踪前沿技术（如 LLM 服务化、虚拟化等），推进新技术在业务场景中的落地实践。

### 任职要求

1. 计算机相关专业硕士学历，扎实的算法基础（LeetCode 中等难度以上）；
2. 精通 Java/Python 至少一门语言，熟悉 Linux 开发环境及常用工具链；
3. 熟悉 Web 服务开发，了解 Web 服务框架，了解 RPC 框架（Dubbo/gRPC 等）、容器化技术（Docker/K8s）、消息队列、ES 等，能够高效地进行后端服务的开发与维护；
4. 熟悉语言 LLM/VLM/AIGC 等多种模型、Agent 技术、RAG 技术、AutoPrompt 技术有一定的使用经验；
5. 常见的开源 Agent 框架，对 openclaw、agent harness 有较好的掌握和项目实践；
6. 了解 GPU 资源调度原理，参与过 AI 竞赛/开源项目，对生成式 AI 的技术架构有系统性认知；
7. 有强烈的上进心和自我驱动，学习适应能力强，乐观自信，能挑战自我不断追求卓越。

## 关键词提炼

- 业务形态：云端 AI 服务、LLM 服务化、虚拟化
- 学历门槛：计算机相关专业**硕士**，算法（LeetCode 中等以上）
- 语言与工程：Java / Python、Linux 工具链、Web 服务框架、RPC（Dubbo / gRPC）、Docker / K8s、消息队列、ES
- AI 能力：LLM / VLM / AIGC、Agent 技术、RAG、AutoPrompt
- 框架实践：开源 Agent 框架、openclaw、agent harness
- 加分背景：GPU 资源调度原理、AI 竞赛、开源项目、生成式 AI 架构认知
