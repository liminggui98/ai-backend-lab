## 职位描述

### 岗位职责

1. 负责地理位置中地图应用、路线导航、定位、底图渲染、POI、路网等相关业务的后端研发工作，承担系统架构设计与能力建设，快速推进业务落地并持续优化产品体验、系统稳定性与整体效率；
2. 深入参与技术方案设计与架构演进，支持复杂业务需求的高质量交付，保障系统在性能、可用性和扩展性上的持续提升；
3. 跟踪行业前沿技术动态，推动 AI、大数据等技术在地理位置服务中的创新应用；
4. 与产品、算法、运营等团队紧密协作，支撑业务目标达成。

### 职位要求

1. 本科及以上学历，计算机、通信等相关专业；
2. 有扎实的编程能力，有优秀的设计和代码能力，Golang、Java、Python、C++ 至少精通其中一种；
3. 深刻理解计算机原理，有良好的数据结构和算法基础；
4. 熟悉常见的存储系统和中间件原理，如 MySQL、Redis、MongoDB、ES、Kafka、Etcd 等；
5. 热爱技术，有较强的学习能力，有强烈的求知欲和进取心，能及时关注和学习业界最新技术。

## 关键词提炼

- 业务域：LBS 中台、地图应用、路线导航、定位、底图渲染、POI、路网
- 工程能力：系统架构设计、性能 / 可用性 / 扩展性、复杂需求交付
- 语言栈：Golang / Java / Python / C++（至少精通一种，标签以 Golang 为主）
- 中间件：MySQL、Redis、MongoDB、ES、Kafka、Etcd
- 基础功底：计算机原理、数据结构与算法
- AI 相关度：低 —— 仅在职责第 3 条提到「推动 AI、大数据等技术在地理位置服务中的创新应用」，无 Agent / RAG / 大模型工程化要求
