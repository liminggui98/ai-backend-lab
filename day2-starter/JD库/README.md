## 二、按方向归类

> 以下三小节属 **Track A**（AI / Agent 相关）；**Track B** 的 8 份已在「一、总览」下方的速览表中单列。

### 1. 大模型应用后端（写服务、扛并发、接模型）

- **腾讯 · 企业微信 AI 应用后台开发**：后台开发 + RAG/Agent 流程研发调优 + 分布式高可用，JD 里 RAG 与 Agent 都是明确职责。
- **字节跳动 · AI 应用后端（Java 方向）**：平台后端全流程（设备管理、任务调度、实时链路、网关）+ 多 Agent 协同框架，Java 技术栈最纯。
- **小米 · AI 后端工程师**：云端 AI 服务、并发架构、GPU 调度、LLM 服务化，门槛最高（硕士 + LeetCode 中等）。
- **比芯算能**：业务架构与中台化 + Agent 框架演进，业务与技术各占一半。
- **阿里巴巴 · ai 应用开发（通用）**：未限定业务域，要求仅"LLM 基本原理 + Prompt 工程实践"，后端栈混大数据（Hive/HBase），属最通用好投的一类大模型应用后端。
- **阿里巴巴 · Java（AI 推理平台 / MaaS）**：百炼 / 通义千问 / Qwen Cloud 的 **控制面与推理网关**，做模型元数据、网关策略、TokenPlan、多 Region 管控；属 LLM 基础设施层后端，要求硕士 + Kong/Envoy 经验。
- **阿里巴巴 · ai 应用研发（商品理解）**：跨境电商品理解（属性抽取、类目预测、多模态表征），是"算法 + 工程"结合岗 —— 既要 LLM 原理、Agent 框架逻辑，又要独立做系统设计与性能调优。
- **百度 · Java 研发（百度云控制台）**：云控制台后端为主，AI 分两层要求 —— 职责要求「AI 工程化意识 + LLM 原理 + Prompt Engineering + ReAct/Tool Use/Multi-Agent 认知」，优先项才要 LangChain/LlamaIndex/AutoGen、RAG/Function Calling/MCP 实战；**经验不限**。
- **美团 · AI 应用工程师（充电宝）**：业务侧 AI 应用落地，Prompt 策略 + Agent 工作流 + 效果评估（准确率/成本/体验），硬性要求 Coding Agent（Claude Code、Cursor、Copilot）实战与 AI 代码 review 判断力。
- **九号公司 · AI 网关产品工程师**：模型接入、路由调度、Token 成本治理、多 Provider 容灾，属 **LLM 基础设施**，但偏产品与运营（技术深度低于阿里 MaaS 那份）。
- **转转 · AI 全栈（HR 系统应用）**：HR 业务系统的 AI 落地，要求 PRD/流程图/字段清单 + Agent 工作流实践，代码要求仅"能看懂"。
- **搜狐媒体**：AI 应用落地 + 技术规划，偏负责人视角。

### 2. Agent（框架、编排、运行时）

- **快手 · Java 研发（AI 数字员工 MyFlicker）**：Agent 流程编排、工具开发与调用、上下文设计 + 研发效能场景；经验门槛最低（页面标 1-3 年），LangChain/LangGraph「了解即可」。
- **蚂蚁集团 · AI 全栈（Agent 开发方向）**：标签含 LLM/RAG/Skill/记忆管理/上下文管理，但**侧重前端**（TypeScript/Node.js/富交互应用），并硬性要求「AI Coding 的全栈开发经验」。
- **小红书 · AI 应用开发（广告方向）**：商业运营平台的 AI 落地，要求「AI infra / 后训练（SFT/RLHF/DPO/CPT）/ AI 应用（Agent/Multi-Agent/Openclaw）/ AI coding（vibe/spec/SDD）」**四选一有深度**，全库对 AI 分层理解最完整的一份 JD。
- **小米 · AI Agent 开发工程师**：Agent 执行引擎、工具调用链路、任务编排、Multi-Agent 协作 + **代码仓库级 RAG**；只要求 3 年经验、无硕士门槛，是本库「高薪 + 低门槛」组合最好的一份。
- **美团 · AI Agent 应用开发工程师（base 北京）**：生产级 Multi-Agent + 端到端 RAG（Chunking / 混合检索 / Rerank）+ Agent 评估框架 + AICoding 工具链；要求懂 LLM 底层原理（Transformer、Token、采样参数），Agent 与 RAG 双栈最完整。
- **美团 · AI Agent 工程师（业务应用开发 / 工程架构）**：同源双版本（40-70K 与 30-60K）。B 端商家场景（经营、商品、订单、客服、营销、数据分析）+ 通用 Agent Framework，Agent 能力项写得最细（编排、记忆、权限、兜底、灰度、成本）；低薪版本额外给出 LangChain/LangGraph/Dify/Coze/AutoGen/CrewAI/MCP 等框架优先项。
- **字节跳动 · Agent 后端（开发者服务）**：面向研发全生命周期的 AI Agent 平台，做研发提效 Agent 产品、评测、Prompt 与知识优化 —— 唯一校招岗。
- **字节跳动 · AI 应用后端（Java 方向）**：多 Agent 协同框架、调度编排、消息通信、工具调用、记忆管理 —— 要求最"工程化落地"。
- **比芯算能**：自研 EasyAgent 框架，重点在工具接入、权限管控、评测反馈。
- **360 集团**：Agent Runtime、模型/工具网关、Agent Loop、MCP/Tool/Skills、评测体系，Agent 概念覆盖最全，但要求 8 年+、5 年 Tech Lead。
- **腾讯**：Agent 作为 RAG 之外的一条业务线，深度中等。

### 3. Track B：业务后端 / 平台 / SRE（同薪资段参照系）

> 这一组的价值不是"投递"，而是**同薪资段的对照系**：看清"不做 AI 也能拿同样的钱"，以及 AI 岗相对溢价/折价在哪。

- **柯莱特 · Java 后端架构师（AI 平台方向）**：AI 中台是数据/训练/推理/模型中心，无 Agent 概念，本质是传统 ML 平台架构岗。
- **字节跳动 · 后端（地图应用、导航方向）**：LBS 地图中台后端，JD 仅在职责第 3 条提「推动 AI、大数据在地理位置服务中的创新应用」，无 Agent / RAG 要求。
- **美团 · 营销后端 Java 工程师**：境外招商与营销系统中台，核心是 Java 后端 + 资金安全（0 资损）+ 多国架构，AI 仅体现为 AI Coding 流程建设。
- **快手 · 后端开发工程师（可灵 AI，2 个版本）**：AI 生成产品的通用后端，写 C 端/P 端平台、多端应用与 B 端 OpenAPI；技术栈 Java/Kotlin + MySQL/Redis/中间件，不涉及大模型或 Agent 研发。
- **小米 · 后端高级开发（稳定性保障 / SRE）**：新零售业务的稳定性与容量治理，做容灾、限流降级、可观测、压测平台；AI 仅出现「运用 AI 高效解决问题」一句。
- **小红书 · 直播 Java 研发**：直播互动业务后端，考 JVM、并发、Dubbo、MySQL 设计与高并发稳定性；加分项为直播推拉流、音视频、IM。全文无 AI 要求。
