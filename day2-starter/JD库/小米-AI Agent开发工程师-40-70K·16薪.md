## 职位描述

### 职位描述

#### 1. AI Agent 功能开发与交付

- 参与 AI Agent 开发平台的核心模块开发，包括 **Agent 执行引擎、工具调用链路、任务编排流程**等，按计划高质量交付功能；
- 根据技术方案完成 Agent 能力的编码实现，包括**代码生成、自动化测试、代码审查**等具体场景的 Agent 开发。

#### 2. Multi-Agent 协作模块开发

- 参与 **Multi-Agent 协作框架**的模块开发与联调，实现任务分解、上下文传递、Agent 间消息通信等具体功能；
- 编写可维护、可测试的代码，确保多 Agent 协同流程的稳定性与正确性。

#### 3. 工具链与基础能力集成

- 负责 Agent 工具生态的接入与适配，完成 **Function Calling 封装、外部 API 集成、工具调用结果解析**等开发工作；
- 参与**代码仓库级 RAG 引擎**的功能开发，包括代码检索、上下文拼装、索引构建等具体模块。

#### 4. 质量保障与持续优化

- 参与 Agent 输出质量评估与 **Bad Case 分析**，持续改进 Agent 效果；
- 参与性能调优与问题排查，保障平台在**大规模代码场景**下的运行稳定性。

### 职位要求

1. 计算机科学或相关专业本科及以上学历，3 年以上软件开发经验；
2. 了解 AI Agent 基本概念与常见框架（如 LangChain、LlamaIndex 或类似框架），**有实际调用 LLM API 的开发经验**；
3. 熟悉 LLM 应用开发的关键环节：Prompt 工程、上下文窗口管理、Agent 插件开发等；
4. 具备良好的沟通协作能力，能在明确的技术方案指导下独立完成模块开发。

### 加分项

1. 有 RAG 系统开发经验，了解向量检索、文本分片、Embedding 等技术；
2. 使用过 Cursor、Copilot、Claude Code 等 AI 编码工具，并有较深的理解；
3. 有 Agent 应用（对话机器人、自动化工作流等）的开发或上线经验。

## 关键词提炼

- 平台定位：AI Agent 开发平台，面向研发场景（代码生成、自动化测试、代码审查）
- 核心模块：Agent 执行引擎、工具调用链路、任务编排、Multi-Agent 协作（任务分解 / 上下文传递 / 消息通信）
- 工具链：Function Calling 封装、外部 API 集成、工具调用结果解析、Agent 插件开发
- **代码仓库级 RAG**：代码检索、上下文拼装、索引构建（比文档 RAG 更难：代码结构、符号关系、长上下文）
- 质量体系：输出质量评估、**Bad Case 分析**、性能调优、大规模代码场景稳定性
- 技术栈：LangChain / LlamaIndex、LLM API 调用、Prompt 工程、上下文窗口管理、向量检索 / 文本分片 / Embedding
- 门槛特点：正文只要求 3 年经验与"能独立完成模块开发"，无硕士要求 —— **本库 Agent 岗中门槛最低的高薪岗**
