## 职位描述

### 岗位职责

- 负责百度云业务端控制台的架构设计与持续演进，推动系统在高可用性、高可扩展性方向的深度优化与落地；
- 负责百度云业务端 API 的规划、设计与开发，制定接口规范，保障接口的稳定性、安全性与易用性；
- 负责百度云业务平台公共服务的设计与研发，沉淀可复用的基础能力，支撑多业务线的快速迭代；
- 负责百度云控制台的用户体验优化，深入理解用户使用场景，持续提升产品的交互体验与操作效率。

### 职责要求

- 计算机或相关专业本科及以上学历，具备扎实的计算机基础理论；
- 数据结构与算法功底扎实，熟悉操作系统、网络协议及数据库核心原理；
- 熟练掌握 Java 开发，深入理解常用设计模式，熟悉 J2EE 体系及主流框架（Spring Boot、MyBatis 等）；
- **具备 AI 工程化意识**，了解大模型（LLM）基础原理及 Prompt Engineering，能够将 AI 能力融入业务系统设计与开发；
- **对 AI Agent 架构有一定认知**，了解 ReAct、Tool Use、Multi-Agent 等核心概念，具备落地 Agent 应用的意愿与能力；
- 学习能力强，动手能力突出，具有持续进取的技术热情；
- 良好的团队协作精神，严谨的工作态度与高质量意识，具备较强的跨团队沟通能力。

### 具有以下经验者优先

- 熟悉 MySQL 数据库设计与性能调优，有 NoSQL（Redis、MongoDB、ES 等）使用经验者优先；
- 有微服务架构设计或微服务化改造经验者优先；
- 熟悉 Linux 操作系统与 Shell 脚本，具备 Python 编程能力者优先；
- 有前端开发经验，熟悉 ReactJS、Bootstrap 等前端技术栈者优先；
- 熟悉 Spring Cloud、Spark、Kafka、Flume 等分布式技术栈者优先；
- **有 LLM 应用开发经验，熟悉 LangChain、LlamaIndex、AutoGen 等 Agent 开发框架者优先**；
- **有 RAG、Function Calling、MCP 等 AI Agent 工程实践经验，或主导过智能化产品落地者优先**。

- 业务载体：百度云控制台（业务端）、云业务 API、平台公共服务
- 后端硬功：Java、J2EE、Spring Boot、MyBatis、设计模式、数据结构与算法、操作系统、网络协议、数据库原理
- 进阶方向（优先项）：MySQL 调优、NoSQL（Redis/MongoDB/ES）、微服务、Linux/Shell/Python、前端（ReactJS/Bootstrap）、Spring Cloud/Spark/Kafka/Flume
- AI 要求（职责要求，硬性但偏"认知"）：AI 工程化意识、LLM 基础原理、Prompt Engineering、ReAct、Tool Use、Multi-Agent
- AI 加分（优先项）：LangChain、LlamaIndex、AutoGen、RAG、Function Calling、**MCP**、智能化产品落地
- 特点：**「经验不限」**——本库唯一不设年限门槛的社招岗；AI 从"认知/意愿"到"工程实践"分为两层要求
