> 与库内其他美团 JD 区别：本份业务载体是**充电宝**（用户端 / 商户端 / 资产运力 / 出海），偏「AI 应用方案设计 + 工程化落地」，不要求 Multi-Agent 平台或框架开发经验。

## 职位描述

### 岗位职责

- **AI 应用方案设计**：围绕充电宝业务场景（用户运营、资产调度、客户管理、出海等），设计 AI 应用解决方案，将大模型能力转化为可落地的业务价值；
- **AI 工程落地**：负责 AI 能力的工程化封装与交付，推动 AI 从技术验证到业务闭环，持续交付可量化的业务结果；
- **Prompt 工程与 Agent 编排**：设计高质量的 Prompt 策略和 Agent 工作流，实现复杂业务逻辑的 AI 自动化处理，持续优化效果和成本；
- **AI 效果评估与迭代**：建立 AI 应用的效果评估体系（准确率、成本、用户体验等），基于数据反馈持续优化模型选型、Prompt 策略和系统架构；
- **行业洞察与技术选型**：持续跟踪 AI 应用层的行业最佳实践和前沿方案，评估新模型、新工具、新框架对业务的适用性，输出技术选型建议。

### 岗位要求

- 本科及以上学历，计算机或相关专业，5 年以上研发经验，其中至少 1 年 AI 应用开发经验；
- **有 AI 应用落地经验**：在实际业务中完成过 AI 应用的完整闭环（需求分析 → 方案设计 → 开发 → 上线 → 效果验证），能讲清楚做了什么、为什么这么做、效果如何；
- **熟悉大模型应用开发**：熟练掌握主流大模型 API 的调用和集成，了解 Prompt Engineering、RAG、Function Calling、Agent Framework 等核心技术；
- **AI Coding 实践能力**：有 Coding Agent（如 Claude Code、Cursor、Copilot 等）的实际项目使用经验，能通过 AI 辅助完成日常开发工作，并具备对 AI 生成代码的 review 和判断能力；
- **业务理解力**：能快速理解业务场景和用户需求，将模糊的业务问题转化为可执行的 AI 技术方案；
- **自驱力强**：能主动发现 AI 在业务中的应用机会，并清晰地表达技术方案和落地思路。

### 加分项

- 有多 Agent 协作或复杂工作流编排的实战经验。
- 有 AI 应用从 0 到 1 落地并跑通 ROI 的经验。
- 有 AI 应用效果评估体系（Eval）的设计和运营经验。

### 岗位亮点

- **真实场景，不缺落地土壤**：充电宝业务覆盖用户端、商户端、资产运力、出海等多条业务线，AI 应用场景丰富且真实——不是找一个问题来证明 AI 有用，而是有一堆真问题等着 AI 来解决。
- **视野开阔**：团队正处于从传统研发向 AI-Native 转型的关键期，你将参与定义 AI 应用在业务中的落地路径，而不是做一个固定方向的执行者。
- **务实的协作氛围**：重视实际产出和独立思考，欢迎带着外部视角和行业经验来碰撞——你的认知和经验本身就是团队看重的价值。

## 关键词提炼

- 业务载体：美团充电宝（用户运营、资产调度、客户管理、出海）
- 工作闭环：需求分析 → 方案设计 → 开发 → 上线 → 效果验证（强调"能讲清楚做了什么、为什么、效果如何"）
- 技术能力：大模型 API 调用与集成、Prompt Engineering、RAG、Function Calling、Agent Framework、Agent 工作流编排
- 效果体系：准确率、成本、用户体验；模型选型、Prompt 策略、系统架构三层迭代
- **AI Coding**：Claude Code / Cursor / Copilot 实际使用经验 + 对 AI 生成代码的 review 判断力（本库唯一把 AI Coding 写进硬性要求的岗位）
- 加分：多 Agent 协作、0→1 跑通 ROI、Eval 体系设计运营
- 软性：自驱、业务理解、技术选型判断
