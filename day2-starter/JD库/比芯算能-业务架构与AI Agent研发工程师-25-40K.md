## 职位描述

### 工作职责

1. 负责小红书核心业务，包括用户体系、笔记内容、社交互动等领域的日常需求迭代与中台化建设，抽象高内聚、可复用的业务模型，持续夯实技术底座。
2. 推进业务全球化架构演进，负责全球多区部署、数据互通及合规闭环建设，支撑海外重点市场落地。
3. 推进业务架构升级与稳定性建设，攻坚高并发场景下的热点、性能瓶颈和数据一致性等核心问题，持续完善容灾、自愈与主动发现机制。
4. 持续建设团队的 AI 工程能力，演进自研的 Agent 框架（EasyAgent），支撑内部提效类 Agent 快速孵化与稳定运行，重点完善工具接入、权限管控和评测反馈等通用能力；结合实际效果逐步探索框架开源。
5. 借助 AI 持续提升代码质量、工程效率和稳定性保障水位，推动 AI 在需求澄清、技术方案、编码、测试及发布等研发全流程中的应用；将容量巡检、风险识别、问题诊断等重复性工作沉淀为可复用的 Agent、Skill 或 Workflow。

### 任职要求

1. 2 年以上 Java、Golang、Python 等主流后端语言开发经验，基础扎实，熟悉主流微服务框架及 Redis、RocketMQ 等常见中间件。
2. 具备高并发、大规模互联网服务的设计与开发经验，熟悉性能优化、数据一致性、稳定性保障及线上故障排查。
3. 具备良好的业务理解和系统抽象能力，能够针对复杂业务问题完成领域建模与架构设计。
4. 具备良好的工程质量意识，能够持续推进代码质量、系统可维护性和稳定性建设。
5. 具备良好的沟通协作、责任意识和项目推动能力，能够独立承担复杂模块的设计与落地。
6. 加分项：深入研究或二次开发过主流 Agent 框架，或具备企业级知识库、Coding Agent、Agent Runtime、MCP、Skill、Workflow、可观测及评测体系等生产实践；有开源项目或技术影响力建设经验者优先。
