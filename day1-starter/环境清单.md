## 4. 四个坑（重装时最容易再踩一次）

1. `.env` 三段 `LLM_*` 全开 → `source` 后最后一段（百炼）生效，以为在测 DeepSeek；
2. `HttpRequest.timeout` 只覆盖到响应头，**body 流没有超时** → 百炼上卡过两分钟（Day 3 用 idle 看门狗解决）；
3. 首帧 `delta.content` 是空串，算成首 token 会把延迟算低（`HelloLLM` 已跳过空帧）；
4. 百炼 DashScope 公共域名已进维护期，新业务走专属空间域名，空间级 key 配公共域名返回 `403 AccessDenied.Unpurchased`。
